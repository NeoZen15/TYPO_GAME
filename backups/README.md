# Backups

`backups/` is an archive-only area for recovery material that was intentionally preserved.

## Intended contents

- historical recovery snapshots
- emergency CSS or content rescue material
- one-off restoration references that should not be treated as active source files

## Rules

- Do not use this directory as a routine working area.
- Do not add new checkpoints here for normal iteration.
- If a new recovery snapshot is unavoidable, use a dated, purpose-specific folder name and document why it was needed.
