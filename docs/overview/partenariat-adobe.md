# Partenariat Adobe / fonderies — démarche

Objet : cadrer comment approcher Adobe (et les fonderies commerciales) pour pouvoir montrer leurs polices dans le jeu et en tirer un revenu, sans risque juridique. Doc de démarche, pas de code. Source légale de référence : `docs/process/checklist.md`, section "NOTE HYPER IMPORTANTE".

## 1) Le principe à garder en tête : deux droits séparés

Un "partenariat" mélange deux choses distinctes. On peut avoir l'une sans l'autre.

- **Droit d'affichage** (juridique). Le fichier de police est un logiciel protégé : interdit de le posséder ou l'héberger sans licence. Ce qui est permis avec une licence desktop : rendre des **images de mots** (spécimen), usage commercial OK. Interdit : montrer l'alphabet complet d'une commerciale.
- **Monétisation** (affiliation). Commission quand un joueur clique et achète/s'abonne via notre lien.

Point crucial : **l'affiliation ne donne pas le droit d'affichage.** Ce sont deux contrats. Le but d'un vrai partenariat est d'obtenir les deux d'un coup, idéalement avec des **visuels d'aperçu officiels fournis par eux** (ce qui supprime la zone grise).

## 2) À qui s'adresser

| Interlocuteur | Pour quoi | Comment |
|---|---|---|
| **Adobe (programme d'affiliation)** | Affiliation Creative Cloud (inclut Adobe Fonts), environ 85 % du 1er mois | Géré par **Partnerize**. Candidature en ligne au programme partenaires Adobe. |
| **Type Network** | Boutique officielle Adobe Originals + fonderies indés | Contact direct pour licences desktop perpétuelles et éventuels assets de preview. |
| **Monotype / MyFonts** | Licences desktop d'un large catalogue (Helvetica, Futura, Avenir…) + affiliation environ 10 % | Programme d'affiliation MyFonts + achat de licences à l'unité. |
| **Fontspring** | Achat de licences claires (modèle "pay once") + affiliation environ 20 % | Programme d'affiliation, taux plus intéressant que Monotype. |

Note : Adobe Fonts via Creative Cloud ne convient pas pour posséder les fichiers (abonnement, interdiction d'extraire/héberger, aucune licence perpétuelle). Pour posséder une typo Adobe à vie, passer par un revendeur (Type Network, MyFonts) ou Adobe Font Folio.

## 3) Ce qu'on leur demande

Dans l'ordre de priorité, pour un partenariat qui règle affichage + revenu :

1. **Accès au programme d'affiliation** (lien traçable, taux, conditions).
2. **Autorisation explicite d'afficher des images de mots** de leurs polices dans un contexte de jeu éducatif renvoyant vers l'achat.
3. **Fourniture de visuels d'aperçu officiels** (idéalement une API ou un pack d'images), ce qui nous évite de générer nous-mêmes les rendus et supprime la zone grise juridique.
4. **Liste des polices éligibles** à mettre en avant.

## 4) Argumentaire (pourquoi c'est dans leur intérêt)

- On leur **amène des abonnés / acheteurs** qualifiés (public passionné de typo).
- Montrer leurs polices dans le jeu, c'est de la **pub gratuite** pour eux : chaque typo reconnue est un point d'entrée "découvrir / acheter cette police".
- On respecte strictement leurs droits : **jamais de fichier de police hébergé**, uniquement des images de mots renvoyant vers l'achat.
- Positionnement : on est le **haut de funnel** (découverte, désir), pas un concurrent.

## 5) Séquencement recommandé

1. **Lancer d'abord en 100 % libre** (OFL/Apache, dont Source Sans/Serif/Code d'Adobe, gratuites, déjà au catalogue). Zéro risque, mise en ligne possible tout de suite.
2. **Générer du trafic et des chiffres** : un partenariat se négocie beaucoup mieux avec de l'audience à montrer.
3. **Approcher les programmes d'affiliation** (Fontspring et MyFonts en premier, taux et conditions les plus simples) une fois le trafic établi.
4. **Ouvrir le mode "grandes typos commerciales"** avec images de mots + liens d'affiliation.
5. **Négocier le partenariat Adobe** (visuels officiels + affiliation) en dernier, avec les métriques en main.

## 6) Points de vigilance légaux

- La France protège davantage les dessins de caractères que les US : **avis juridique avant lancement commercial** du mode commerciales. (Ce doc n'est pas un avis légal.)
- Règle absolue à tenir en toutes circonstances : **on affiche des images, jamais des fichiers de police non licenciés.**
- Alphabet complet interdit pour les commerciales ; mot-spécimen OK.
